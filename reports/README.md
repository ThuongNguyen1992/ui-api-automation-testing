# reports/

Everything here is generated by a run and not committed (only this file is). The latest CI run is published at
**https://thuongnguyen1992.github.io/ui-api-automation-testing/** (Allure, with trend history).

| Folder | Written by | Content | Open |
| --- | --- | --- | --- |
| `allure-results/` | Allure reporter | raw results of the last run (cleared by the global setup) | — |
| `allure-report/` | `npx allure generate` / end of a local run | Allure HTML report + `overview.png` (used by the Google Chat card) | `npm run report:allure` |
| `html-report/` | Playwright HTML reporter | Playwright report with traces of failed tests | `npm run report:html` |
| `json/results.json` | Playwright JSON reporter | input of the job summary, Google Chat card and report history | `npm run report:summary` |
| `xml/` | JUnit reporter | results for CI tools | — |
| `test-results/` | Playwright | screenshot, video, `error-context.md` of failed tests | — |
| `k6/` | k6 `handleSummary` | `<scenario>.json` (raw metrics) + `<scenario>.md` (table) | `npm run k6:smoke` |
| `.auth/` | `Setup - UI Auth` project | signed-in session reused by the UI tests | — |
